# 从站位推导可见画面

用于门口/桌边并列对话、正反打、跨组续场、低位手部细节及多人前后景。状态来源与动作链仍按[整本模式第3节](full-script-mode.md#3-全剧共用资料与连续场景状态)管理。本页解决的是：人物状态已写正确，但镜头正文没有充分说明从该机位实际能拍到什么。它不保证下游模型服从文字。

## 1. 先核对镜头能否同时成立

起草或更换机位、景别后，把这一镜当作一张静止画面检查，再写运动。用已有内部镜头记录回答下表；不用在成品新增四个审计字段。普通清楚镜头可简写，反打、续场首镜和出现冲突的镜头应留下具体依据。

| 核对项 | 可核对的结果 |
|---|---|
| 相机与背景 | 相机在哪个固定锚点一侧、拍向哪里；人物身后实际是什么、哪些锚点在相机后方。选择足以区分机位的背景或边缘参照；紧特写没有参照时标为本镜不可见，不能硬塞背景 |
| 身体与脸 | 依据既定胸向和头向，摄影机看见胸前、侧身还是背部，以及哪一侧脸。头转向对手不自动改变胸向；“正侧脸”要由相机位置实现 |
| 可见集合与边界 | 本镜实际可见哪些角色，包括肩、手、倒影；单人镜取景如何避开近旁对手。画外对手保留必要位置/声源方向，其余持续状态留在组头和状态记录 |
| 动作与细节覆盖 | 本镜必须看到的部位、接触点或动作终态是否在取景内、未被遮住。需要看清的细节和只须持续存在的状态分开 |

从静帧结果反查原句：能否在不移动人物、家具、不改变接触的情况下满足该镜所有要求？不能时，先调整相机与实际取景覆盖；需要改变剧情动作或已锁定状态时回到动作编排，不用一句“保持不变”掩盖矛盾。初态可行不代表过程可行，转头、穿门和交接仍要核对沿途遮挡与终态。

把答案融入原有格式：单人镜仍只用`画面简介`，开头保留景别、基础角度、简单运镜和焦点；分号后选写可见背景、人物位置及可见身体面，再写动作。多人镜仍用原三字段。用具体的画面结果缩小歧义，不复制整份状态台账，也不机械要求每镜全身或全景。

## 2. 三种容易相互竞争的描述

**画外状态与画内构图。** 一个角色在场不等于需要入画。组头保留床边、桌边等持续状态；单人镜只展开实际可见人物、必要画外互动方向与声源，不在同一句中又详细描绘远处多人的坐姿表演。目标为单人镜时，写“另一人半步外”还需说明其在画外的哪一侧；半步距离较近，另核对裁切能否避开肩背。不能通过删掉角色状态来伪装连续性。

**细节清楚与取景范围。** “面部近景”不能同时承诺看清腿旁的伤手或脚下接触。若本镜需要脸与低位手同框，明确从头到手下方的实际覆盖，再选择匹配景别；只需眼神反馈时，手可以画外但接触状态继续有效。调整机位后仍看不到所需伤处时保留缺口，不擅自抬手、翻腕、扶椅来展示。全组的“伤口/脚步/通路可读”要落到承担该任务的镜头，不解释为每个近景都必须展示全部部位。

**反打与固定胸向。** 焦点换人、由中景改中近景不必把相机移到人物连线另一侧。门口两人面朝病床，从病床侧拍时可以看见胸前且身后是走廊；换到走廊侧朝病床拍，则按原身体方向呈现相应背侧/侧背。若这时仍要正脸与胸前，应重新选择可行机位，或按源文安排有依据的身体转向。不能既写身体不转，又要求两个相反方向机位都拍到同一胸前。

## 3. 可生成片段示例

以下是匿名化的空间/构图片段，不是完整组，也不新增剧情台词或固定所有场景的调度。

**门口单人续场：** 中近景，平视斜前方固定拍摄，焦点落在门框旁女子；相机在病房内床尾拍向入口，画面只收入女子头至胸部，身后是窗侧门框边缘和门外走廊。她胸口朝病床，摄影机见其胸前；头偏向画外另一门框的医生，脚下和倚框位置保持。床在相机后方，陪床者的位置仍沿组头状态保留。

**伤手与反应同框：** 中景，平视右前侧固定拍摄，焦点落在站立老人；取景覆盖头顶至大腿中段，脸在上部、自然垂下的右手在下部。右手停在右腿外侧，与身旁椅子留有空隙，摄影机从伤处可见的一侧观察；她低眼看手，接触状态不变。只有伤处位置已知且该机位确实看得到时，才使用“伤处可辨”；未知时保留待核对。

**法庭建立镜到人物反应镜：** 建立镜从旁听席中央过道朝法台，法官正面位于远处，控辩双方依原胸向呈背侧或侧背；下一镜需要检察官正侧脸时，将摄影机放到其法台侧斜前方，并按该角度选择真实窗边背景。检察官身体仍朝法台，不能因需要正面表情而转向旁听席。近远层次也须从相机位置推导，不能让本应在相机后方的人强行成为画内前景。

## 4. 将成片错误变成回归样例

媒体异常先保留实际帧时刻、当前正文和可恢复的实际生成输入；证据边界按[资产管控第3B节](global-asset-control.md#3b-实际生成输入版本)。将问题分为：正文可证明的冲突/歧义、成片偏离明确指令、尚未验证的原因假设。输入未知时不能把某版文字或参考数量定为根因。

下面的候选错误是供技能复核的构造例，不声称它们曾逐字出现在某次实际生成输入中。更换角色名和地点后仍应能判定；验收看实际几何和动作，不按是否出现“保持一致”评分。

| 样例 | 候选问题或条件 | 应有处理 |
|---|---|---|
| 反打胸向 | 身体始终朝床，却要求从走廊侧看病床时仍见胸前 | 指出投影冲突；改相机或有源依据的动作，不镜像人物/房间 |
| 画外座位 | 前段分坐床两侧，后段单人镜却写两人并排坐背景墙边 | 识别未经动作支持的换座与可见人数冲突；保留座位，修构图 |
| 跨组入口 | 同地点续场只写“继续对话”，未说明本镜背景与可见身体面 | 从有效末态派生新景别的画面；用固定背景和胸向核对，避免重新摆人 |
| 伤手展示 | 脸部近景同时要求腿旁伤手清楚且不抬手 | 调整真实覆盖/任务分配；不增加扶椅或抬手等无依据接触 |
| 法庭正脸 | 从旁听席看法台，却让朝法台的检察官正面迎镜 | 区分建立镜背侧与法台侧反应机位；不为脸部可读而转人 |
| 合理反打对照 | 桌边两人面对面，相机保持既定轴线一侧，正常反打改变屏幕投影，世界位置与背景均正确 | 可以通过；跨轴另查有依据的过渡，不能只凭世界位置未变放行，也不能把屏幕换边本身判为身体反转 |
| 必需转身对照 | 源文明写转身去开门 | 保留可见转向过程和结果，更新状态；不能用朝向锁定删剧情 |

修订后先用文字样例验证新规则是否改变了实际构图决策，并保留旧版已经通过的对照。文字试跑通过不等于视频效果改善。需要实测时，在已授权制作范围内选一个最小失败片段，保存输入，比较改前/改后；先只改变提示词的画面约束，保留角色、参考、模型、时长及平台支持的其他条件，随机种子仅在平台支持时固定。再单独检验参考组合或制作拆分，不能一次全改后宣称找到原因。

引用选择按[资产管控第3节](global-asset-control.md#3-有资产流程查看适配绑定)，首帧和分段制作按第3A节。仅因角色在组头维持画外状态，不自动把其定妆图作为本段可见主体输入；有实际入画镜段或明确控制用途时记录用途。纯文字/技能任务输出可用改法与待验证项，不自动制图、生成视频或更改远端绑定。
