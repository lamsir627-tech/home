# 叙事证据与依赖

在误会、隐瞒、伏笔、反转、跨时间线或上游修订影响下游时使用。简单直线场景可把以下内容合入已有任务记录，不额外造一整套文件。本参考补充长文本流程的第05、06、09、10步，不改变 `source-ledger.json` 或 `storyboard-map.json` 的 schema。

## 让全剧理解约束当前镜头

按原文单元定位关键节拍，记录“触发/证据 → 角色行动 → 可见结果 → 状态变化”。镜头选择服务于当前可见信息的获得、确认、误读或遮蔽；不能借钩子、构图或微表情先交代原文尚未允许揭示的事实。

有叙事歧义时，在现有记录内区分：

| 项 | 最小记录 |
|---|---|
| 事实 | 内容、源单元、叙事时间、生效/结束事件；原文明示与推定分别标记 |
| 角色认知 | 角色、知道/相信/怀疑/误解/未知、信息来源、何时获得；其自述不自动等于客观事实 |
| 观众信息 | 此处之前已展示什么、当前允许展示什么、后续揭示位置；公开揭示时间可晚于人物知情时间 |
| 当前节拍 | 触发事件、行动/反应、落点、不可提前透露的信息 |
| 依赖 | 使用该事实的集/组/镜、资产/状态修订、检查状态 |

原文后段追认角色早已知情时，区分“此角色何时知道”与“观众何时知道”。回看前段可以检查其不矛盾，但不能把后段才公开的真相直接写成前段得意微笑、特写泄密或新增暗示。原文只允许含混时，保留含混；没有取得证据的角色不能因全剧分析而突然知道。

假设包括必要的非剧情性拍摄细节，不包括新增原因、关系、阴谋、物证内容、画外完成的关键动作。缺口影响关键因果时记录未决项并只询问这一点；独立部分继续。

## 证据如何进入实际画面

每条必需动作关联具体源单元和成品镜头，检查发起、接触/变化与结果是否真的可见。按[动作与对话时序匹配](source-text-and-shot-rules.md#3c-剧本动作与人物对话时序匹配)分析对话前后的画面，把动作执行者、前提结果及发声/反应触发点写入已有节拍记录。说话者、视觉焦点和信息接收者分别判断：对白可留在画外，听者镜头只表现其此时能接收到的信息。记录听见/看见的实际通道；长台词跨镜时，把反应触发绑定到真正说出关键信息的片段，在关键信息到达之前不能先惊觉或认出。

情绪沿“前态 → 当前触发 → 可见泄露或控制 → 余波”延续。普通对白保留一个有用的变化；不要给每句话添完整表情链。镜头反应要受角色认知与观众揭示共同约束。先满足时间/动作契约，再选可实现的表演。

物理状态沿用 [整本模式第3节](full-script-mode.md#3-全剧共用资料与连续场景状态)：地点几何、连续实例、道具持有人/手、机位拍摄侧彼此分开。镜头左右由机位推导，不能因焦点切换改写世界位置。道具细节镜只能展示此处原文允许看见的内容；不能虚构可读文字、第二件道具或尚未公开的破损特征。

## 可完成的批次与共享上下文

保留完整源文与索引，首次完整阅读后在后续批次检索精确原文及必要依赖。可用上下文充足、源范围简单时一次处理完整场景或单集；复杂回忆/多线叙事/大量换装时缩小至有可靠交接的自然单元。不设置固定字符数、固定组数或基于模型宣传额度的批次目标。

每批只携带当前有关的原文、角色认知、观众揭示界限、场景入态、资产版本、前两镜和未决项。共享资料可复用，但已读覆盖、词句与状态依据均需能回到快照。主模型整合独立分析结果，不能把相互未知的场景末态当作已核对事实拼接。

## 用户更改后的最小重审

先记录更改的是源文、制作参数、拍摄推定还是资产引用；保留原文快照，不把分镜纠正偷偷写进剧本文字。把受影响产物标为“需重审”，保留旧报告及旧版本。

| 改动 | 必需重审 |
|---|---|
| 台词/说话者/源集界 | 新源修订、分类、全部相关片段和播放顺序、语言估时、受影响组/镜及最终汇编核对 |
| 持物手/归属/伤势/角色认知 | 起点事实与使用它的后续镜头、动作和场景入/末态；持续事实跨实例追踪 |
| 机位/焦点/画幅 | 实际画面几何、轴线/视线/手与道具可读性、重叠三镜窗口及相邻组景别；不自动改世界位置 |
| 资产几何/衣装/时段 | 匹配/绑定、当前镜头及依赖该版本的下游；不能沿用旧资产审核结论 |
| 仅格式或措辞 | 改写后的可读性与契约；音频字段或镜序触及时重跑文本核对；成品hash变更需更新当前报告依据 |

传播到状态重新一致或原文明确重新建立该事实为止，并记录停止依据。换场只可能结束局部站位继承，不能自动结束持物、伤势或知情的影响。独立未受影响成品继续有效；不要为一次修正重做全剧，也不要只替换出错句而保留失效末态。

例：用户纠正第1集钥匙始终在林夏右手。核对这是原文纠错还是拍摄推定纠错，定位所有取钥匙、接触、递交、插锁及连续入/末态。即使第2集换场，只要同一钥匙仍在她手里就继续检查；有明确放桌并重新拿起的事件时，按该事件重建后续依据。只改机位可以改变画面左右，不能把右手变左手。文本核对通过本身不能证明此修正已经传播完整。

## 最终语义审阅

以精确源文与实际成品为证据，逐项找出：遗漏的必需动作、凭空新增事件、人物越界知情、观众提前获知、错实例继承、道具无因换手、情绪无触发跳变。每个发现给出源ID、成品集/组/镜、具体不一致及修复范围。用独立子代理审阅复杂任务时，不提供主模型“应该通过”的结论；有无法判断的边界要标明不可核对。

该审阅是文本与分镜计划审阅；没有实际生成视频、TTS或参考图时，不声称已验证成片、实际发声时长或图片绑定效果。
