# 拆分分镜（30秒动态节奏版）

## Goal

Convert a script into video-generation prompt groups. Each group represents exactly 30.0 seconds of screen time and follows this core logic:

`生成任务 + 主要主体 + 场景与环境状态 + 情绪目标 + 光线与色彩设计 + 视觉风格 + 分段脚本 + 单镜头提示词 + 30秒合成提示词`

Write in Chinese by default. If the user specifies a video model (e.g., Runway, Luma, Kling, Sora), target platform, aspect ratio, language (e.g., English prompts for Western models), or specific visual style, adapt the prompts accordingly.

Before generating any output, read and apply both mandatory reference files if available:
- [source-text-and-shot-rules.md](references/source-text-and-shot-rules.md) for source preservation, subtitle exclusion, timing, opening hooks, shot language, dialogue speed, prompt cleanliness, asset references, and confirmation checks.
- [lighting-and-color-optimization.md](references/lighting-and-color-optimization.md) for lighting classification, content-based custom design, reference profiles, prompt integration, and continuity checks.

**Fallback Rule (如果引用的 md 文件不可用或未加载时使用)**：
- 严格锁定原文台词/旁白/VO，不得改动文字；`【字幕：...】` 仅作为后置字幕标记，绝对不写进画面描述或 AI 视频提示词。
- 采用三点式光影（主光、辅光、轮廓光/环境光）与情绪调性相契合的色彩基调，确保同场景连续性。

## 原文与连续性硬规则

以下规则同时约束分段脚本、单镜提示词及整组提示词；镜头密度、钩子、时长与光色设计不得覆盖这些规则，引用文件与本节冲突时以本节为准。

### 前情人物动向与站位梳理

- 每次拆分第 N 集前，先读取前面各集的“人物动向与站位梳理”，追踪本集涉及人物最近一次已知状态，重点核对上一集结尾，不凭记忆重置人物位置。
- 每人记录：来源集数/场次及原文依据、所在场景、出入场与移动路径、相对门窗/桌椅等固定参照物的位置、朝向、视线目标、与其他人物的相对位置及距离、持有道具、未完成动作。未出场不等于已离场。
- 首集注明“首集，无前情”。有前集原文但无梳理时先补建；前集材料缺失或衔接冲突时列明问题并请求补充，不编造前情，可先处理不依赖该信息的段落，受影响镜头不得标为通过。
- 每集结束输出“本集人物动向与站位梳理（供下一集先读）”，保留本集未更新人物的最后已知状态及来源，供后续集数读取。

### 动作有据与持续动态

- 每个角色动作、表情变化、进出场、移动和道具交互须能回溯到具体原文。不得为凑满 30 秒、达到镜头数或制造钩子擅加转身、走近、抬手、点头、握拳、落泪等动作或反应。
- 动作依据与摄影调度分别记录。原文未明确初始左右站位时，可建立不改变剧情的最小构图安排并标记“调度设定”，此后保持一致；涉及是否在场、能否看见及剧情因果的不确定信息须先澄清。
- 镜头描述和两类视频提示词禁止“定格”“冻结画面”“静止画面”“时间停住”“如照片般不动”等非动态表现及其同义替换。连续性记录可以描述位置状态；固定机位不等于冻结画面。
- 动作少时，合理拆解原文已有的连续动作，或使用不改变人物关系的缓慢推镜等摄影运动，不添加人物动作、环境事件或重复动作填时。仍无法满足自然时长与分组要求时说明冲突并请求补充，不删词、加戏或冻结画面。

### 禁用套话与情绪动作化

- 新写的镜头描述、表演说明、音效及两类视频提示词禁止“倒吸一口凉气”“倒抽一口冷气”“倒吸冷气”等同类套话及变体；不使用“心头一震”“心如刀绞”“如遭雷击”等文学化反应替代可见表演，也不将禁用说法原样塞进负面提示词。
- 新写的人物外观、情绪与表演描述、镜头描述及两类视频提示词禁止“双眼通红”“眼眶通红”“眼睛发红”“眼底猩红”“双目赤红”“眼中布满血丝”等同类眼部泛红或充血描述及同义变体，不以眼部颜色变化代替情绪动作。不得通过换词或写入负面提示词规避；应回到原文已有的具体动作表达，不能自动替换成落泪、瞪眼、握拳等无依据反应。锁定原文台词中的此类词仍按下述原文保留规则处理。
- 描写人物情绪、心理时，必须同时写清承载该情绪的具体动作：谁、朝向谁或什么、身体哪个部位如何运动、动作怎样进行或结束。不能只写“伤心、痛苦、愤怒、绝望”，也不能仅增加“非常、极度”等程度词。心理依据放在情绪目标或表演说明中，纯视觉提示词写可拍摄的表现。
- 动作必须来自原文已有行为或其不改变行为含义的可见展开；情绪标签本身不构成新增动作的依据。不得见到愤怒就添加摔杯、见到伤心就添加落泪，也不得仅用推镜替代人物的情绪动作。若原文只有心理、没有可用行为，标记“表演动作依据不足”并请求补充，不将该人物镜头标为通过。
- 例如原文为“她伤心地把信推回他面前”，可写“她的手将信沿桌面推回对方面前”，并在情绪目标中注明伤心；不能只写“她十分伤心”，也不能追加原文没有的撕信、转身或哭泣。
- 上述禁用范围是新生成的描述。锁定的原文台词、旁白、VO、OS若含这些词，仍须逐字保留在台词轨，不扩写到视觉提示词；原文非台词叙述中的套话应按已有动作转换，依据不足则列为待补充项。

### 台词逐句逐字锁定

- 按原文顺序为全部角色台词、旁白、VO、OS/内心独白建立唯一编号，保存说话人、声音类型、原文全文及对应组/镜头。保留称谓、语气词、重复词和标点，不改错字、不概括、不润色、不翻译或调整顺序。
- 只有明确标记为后期字幕的内容才隔离到字幕参考；同一文字若也是说出的台词，仍须完整保留在台词轨。纯视觉提示词不含台词不代表可从分段脚本省略台词。
- 优先在完整句之间分组。长句跨镜保留同一编号并标明连续片段，按顺序拼接后必须与原文逐字一致，不重播、不漏片段，不用省略号代替原文。
- 交付前按编号从分段脚本回收全文，逐字比对原文，并核对说话人、声音类型和顺序。每个原文编号恰好覆盖一次；原文本来重复的句子各自保留编号。逐集报告原文句数、已覆盖句数、漏句、增句和文字差异，全部一致才可标 PASS。
- 台词无法自然说完时调整镜头时长或增加 30 秒组，不删词或超速念白；视觉提示词的语言选择不改变锁定台词语言。

### 空间站位与视线连续

- 每场建立固定空间参照物、人物世界位置和对话/动作轴线，再记录当前机位下的画面左右、前后景、朝向及视线落点。区分世界位置和画面左右，反打不代表人物实际换位。
- 逐镜、逐组、逐集核对“前段结束状态→后段开始状态”；位置、朝向、视线和道具持有者变化须有原文动作或明确转场支撑，禁止瞬移、无依据换手及无故反向。
- 正反打保持轴线同侧，视线方向、距离和高度互相匹配；看向画外人物时明确目标及相对方位，不让离场、被遮挡或不在视野内的人物凭空成为可见目标。
- 摄影机越轴时用连续运镜或中性镜头交代空间变化，不擅加人物转身修补。镜头描述、单镜提示词和整组提示词共用同一套位置与视线记录。

### 剧情动作完整性核对

- 拆镜前按原文顺序给关键动作、人物进出场、道具交接和信息揭示建立事件编号，记录原文位置、执行者、对象及结果，并映射到组号/镜号。事件与台词分别核对，不能以台词已保留代替剧情事件已呈现。
- 一个事件可以跨镜展开，但不得遗漏、重复发生、倒置因果或提前揭示信息；原文仅通过台词告知的事件保留其告知方式，不擅自新增回忆或演示镜头。
- 交付前逐项核对事件覆盖、先后顺序和结果；未覆盖或改变含义时不得标 PASS。

### 单镜头动作容量限制

- 每镜围绕一个主要动作或同一目标下可连续完成的动作链展开；动作数量服从镜头时长，不在 1–2 秒内堆叠起身、走近、取物、转身及长台词。
- 按人物距离、动作步骤和自然速度检查是否做得完；与台词同时发生的动作标明并行，必须先后完成的步骤按顺序计时，不靠超速表演压缩。
- 容量超出时延长镜头或拆成连续镜头，在 30 秒组内重新分配时间，必要时增加组数；不得删掉原文动作、跳过必要步骤或添加动作填时。

### 声音与画面对应关系

- 每段声音标明台词编号、声音来源人物、声音类型、说话人是否入画及口型要求。区分现场对白、画外对白、旁白和内心独白，不仅凭 VO/OS 缩写猜测；原文含义不明确时标记待核对。
- 现场说话人入画且嘴部可见时，对应本人台词口型；画外对白不驱动画内听者口型，旁白和内心独白不让角色张嘴代说。原文有同步开口行为时另按对应对白处理。
- 切到听者反应时，正在说话者的台词可跨镜连续，沿用同一编号与连续片段，不重读或截断；无原文依据不增加抢话、重叠对白或听者动作。
- 声音来源和台词文本保留在声音/台词字段；纯视觉提示词仅描述相应可见说话行为，仍不嵌入台词文本。

### 跨镜动作接续

- 同一动作跨镜、跨组或跨集时，以事件编号连接，记录前镜结束阶段与后镜开始阶段，以及左右手、道具位置、身体朝向和运动方向；后镜从前镜已达到的状态继续。
- 已完成的步骤不得重做，未完成的必要步骤不得凭空跳过。例如前镜已经拿起信，后镜从持信状态继续原文规定的后续动作，不再从桌面拿一次，也不擅自添加读信。
- 区分人物自身左右手和画面左右，反打不改变持物手；换手、转身和移动必须有原文依据。原文明确转场或时间跳跃时注明，不强行补拍不存在的过渡动作。

## Workflow

0. **前情核对**：执行“前情人物动向与站位梳理”，确认本集起点及待澄清项后再拆分。

1. **全局分析（Script Analysis）**：通读剧本，识别主要人物、人物关系、场景地点、时间、核心冲突、关键道具与情绪转折点。
2. **锁定台词（Text Locking）**：提取原文 VO、旁白及角色台词作为不可变锁定文本（Locked Text）。严禁改写、润色、增删或颠倒顺序。明确将 `【字幕：...】` 隔离为后期字幕参考，不进画面视觉提示词。
3. **30.0秒精准分组（30-Second Grouping）**：按时间顺序划分为 `第N组（00:00-00:30）`、`（00:30-01:00）` 等区间。结合自然台词语速（每秒 3.5-6 个汉字）微调组边界，确保台词完整流畅。
4. **动态单镜头拆解（Dynamic Shot Breakdown）**：
   - 将每组拆解为 **10-15 个** 快慢结合的高密度短剧镜头。
   - **严禁机械等长平摊**：绝对禁止将 30 秒机械平摊为固定时长（例如禁止 10×3.0s 或 6×5.0s 这种死板划分），即使源文件中写有固定秒数，也必须根据戏剧张力、情绪转折与台词长短重新规划快慢交替的视听节奏。
   - **步长规范**：镜头时长必须以 **0.5 秒为最小单位**（如 1.0s, 1.5s, 2.0s, 2.5s, 3.5s, 4.5s），且单组所有镜头时长之和必须精确等于 **30.0 秒**。
5. **黄金 2 秒钩子与镜头节奏（Hook & Visual Pacing）**：
   - 前 2 秒采用短镜头（1.0s - 1.5s），优先使用特写（CU）、眼神/微表情、动作细节、主观视角（POV）或强反应镜头做视听钩子。
   - 情绪高潮/快速反应使用短镜头（1.0s - 1.5s），完整表达长台词或连续肢体动作使用较长镜头（2.5s - 4.5s）。
6. **光色分类与设计优化（Lighting & Color Optimization）**：将本组分类为 `光线与色彩1`、`光线与色彩2`、`光线与色彩3` 或 `自定义光线与色彩`。合理设计主光方向、辅光/轮廓光、冷暖色温对比、饱和度及材质反射，融入场景环境描述。
7. **双轨提示词输出（Dual-Track Prompts）**：
   - **单镜头视频提示词（单镜 Prompt）**：为每个单镜头生成独立、纯画面、可直接复制到 AI 视频生成工具（如可灵、Runway、海螺等）中的提示词。
   - **30秒合成提示词（整组 Prompt）**：将整组要素融合成一段流畅的全局场景提示词，适用于支持长视频/连续生成的模型。
8. **干净度与自检（Cleanliness & Self-Check）**：禁止出现字幕渲染指令、BGM/背景音乐描述、负面词或导演说明。逐句逐字核对台词，逐镜核对动作依据、动态描述、站位和视线；未核对或有差异时标待核对/FAIL，不预填 PASS。每集最后更新人物动向与站位梳理。

## 30-Second Grouping & Shot Rules

- 标题格式：`### 第N组（MM:SS-MM:SS）`
- 组时长严格固定为 `30.0秒`。
- 镜头时间戳格式：`【单镜头N】(MM:SS.S - MM:SS.S / X.X秒)`。例如：`【单镜头1】(00:00.0 - 00:01.5 / 1.5秒)`。
- **时长与节奏禁忌**：
  - **禁止均匀平摊**：即使原剧本标注了固定模板，也必须覆盖重新规划为符合戏剧节奏的长短镜组合（1.0s/1.5s/2.5s/4.0s 等）。
  - 步长必须为 **0.5 秒倍数**，精准校验总和为 30.0s。
- 构图锚点：对于“对视、对峙”等抽象关系词，必须补充空间方位锚点（如：过肩反打、侧面双人特写、POV视角、前景背影）。
- 画面干净度：严禁出现 "subtitle", "text on screen", "Chinese text", "watermark", "BGM", "背景音乐" 等会导致画面出现文字或混淆视频模型的词汇。

## Field Guidance & Quality Bar

- **生成任务**：必须使用动作动词（如：生成、呈现、拍摄、刻画、推进），说明视频需生成的视觉核心内容。
- **主要主体**：按优先级列出画面中可见的人物或物体，包含年龄段、服装、物理状态及关键道具。
- **场景与环境状态**：具象化空间描述，包含地点、时间、天气、灯光源、建筑/家具锚点。
- **情绪目标**：点明本组 30 秒内观众应感知到的情绪转变（如：从压抑到爆发），并对应到承载该情绪的原文动作及镜头编号，不只罗列情绪或心理词。
- **光线与色彩设计**：包含主光方向与质感、辅光/轮廓光、冷暖色温关系、对比度/饱和度及材质漫反射。
- **单镜视频提示词**：
  - 必须是**纯视觉动作与场景描述**，直接可用于 AI 视频生成。
  - 包含主体、动作、镜头运动（如：拉远、摇镜、跟拍、特写）、光影氛围与视觉风格。
  - 绝不包含台词文本、字幕要求、BGM或元说明词。
- **30秒合成提示词**：将整组的背景、主体、光影与主要动态融合成一段连贯段落。
- **分镜自检**：必须使用给定的结构化标签格式输出，保持简洁干净；另附 `[套话检查: PASS或FAIL] [情绪动作化: PASS或FAIL或不适用]`。逐镜检查新写描述无禁用套话，且人物情绪有明确动作及原文依据；无人物情绪表达的镜头才可标不适用，动作依据不足标 FAIL。
